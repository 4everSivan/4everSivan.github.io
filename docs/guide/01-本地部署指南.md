# 本地预览与发布指南

> **created**: 2026-11-06 ｜ **last-change**: 2026-11-09 ｜ **status**: active

文档 ID：GUIDE-DEPLOY。本指南描述当前站点的真实运行方式：首页由根目录 `index.html`、`assets/css/style.css` 与 `assets/js/main.js` 组成，**运行时无构建、无依赖**；文章页在部署/预览时由 `scripts/build_posts.py` 从 `posts/*.md` 生成（构建期依赖 `markdown` 与 `pygments`，含数学公式的文章另需 `matplotlib`；产物不入库，契约见 [博客文章设计方案](../devel/design/02-博客文章.md)）。

## 1. 前置条件与配置

- 平台：任意现代桌面浏览器（Chrome / Safari / Firefox 最近两个大版本）。
- 运行时：不需要 Node、Go 或包管理器；`python3` 仅用于可选的本地静态服务器与文章构建。
- 文章构建依赖：`markdown` + `pygments`，文章含数学公式时另需 `matplotlib`（缺失时构建报错退出）；装在 `local/venv` 自包含虚拟环境（不污染系统 Python）；CI 在 Actions 内自行安装。
- 字体：页面使用系统字体，中文回落到宋体（`Songti SC` / `SimSun`），拉丁字母与数字使用 `Times New Roman`。系统缺少对应字体时按 CSS 字体栈继续回落，功能不受影响。
- 配置与密钥：站点不需要环境变量、密钥或数据库；不存在需要注入的敏感配置。

## 2. 构建与启动

```sh
# 方式一：首页直接用浏览器打开（file:// 即可；此路径不含文章列表，BLOGS 为空状态占位）
open index.html

# 方式二：构建完整站点（含文章页与首页列表注入）后预览
local/venv/bin/python scripts/build_posts.py --out local/site
open local/site/index.html                                   # 首页（BLOGS 已注入列表）
open local/site/posts/2026-11-08-machine-learning-intro/index.html   # 文章页

# 方式三：本地静态服务器，便于模拟真实路径与相对链接
python3 -m http.server 8000 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8000/
```

首次准备构建环境：

```sh
python3 -m venv local/venv
local/venv/bin/pip install markdown pygments matplotlib
```

成功判断：

- 首页返回 HTTP 200，控制台无报错；
- 顶栏、引文、PROJECTS、SKILLS、BLOGS、页脚区块完整显示；构建产物首页的 BLOGS 为文章摘要列表，仓库源 `index.html` 的 BLOGS 仍为 COMING SOON 占位；
- 文章页标题/日期/代码高亮/脚注正常，资源引用为 `../../assets/`；
- 窄窗口（≤ 640px）下导航与列表正常换行，无横向滚动；
- 首次加载自动匹配浏览器浅色/深色偏好；点击顶栏主题按钮可切换并记住选择；两套主题文字对比度正常。

停止本地服务器使用 `Ctrl+C`；构建产物在 `local/site/`，其清理由人类决定（`local/` 红线）。

## 3. 发布与部署实况

站点是纯静态文件，由 `.github/workflows/pages.yaml` 在推送到 `main` 时部署：workflow 运行 `scripts/adflow-verify`，安装构建依赖后执行 `scripts/build_posts.py --out public`（生成文章页、注入首页列表、复制 assets），把 `public/` 上传为 Pages artifact。发布流程：

1. 在授权范围内运行 `scripts/adflow-verify` 并取得 Exit 0；
2. 按项目提交规范提交；
3. 合并与推送需独立授权；
4. 在 GitHub 仓库 Settings → Pages 确认 Source 为「GitHub Actions」；
5. 推送后查看 Actions 中 `Deploy static site to GitHub Pages` 的运行结果；
6. 发布后访问 `https://4eversivan.github.io/` 核对线上表现。

## 4. 已知失败与处理

| 现象 | 排查 | 处理 |
|---|---|---|
| 页面无样式 | 检查 `assets/css/style.css` 路径与大小写 | 修正相对路径后刷新 |
| 中文不是宋体 | 当前系统缺少 `Songti SC` / `SimSun` | 安装字体或按设计文档扩充字体栈 |
| 刷新后主题回到系统偏好 | `localStorage` 被清理或在隐私模式下不可用 | 手动选择无法保存时的预期回退 |
| 主题按钮无反应 | JavaScript 被禁用或脚本未加载 | 属预期；主题按钮依赖脚本 |
| 线上仍是旧页面 | Pages workflow 失败或 Source 不是 GitHub Actions | 查看 Actions 日志与 Pages 设置，避免反复强刷掩盖问题 |
| 开启「减少动态效果」后仍有动效 | 设计选择：入场、卡片悬停、技能轮播、主题揭示、引文展开、字标回顶与切页过渡均不随 `prefers-reduced-motion` 关闭（C010/C012/C016，见首页与文章设计） | 属预期；仅页面原生锚点滚动改为瞬时 |
| 构建报「构建需安装 matplotlib」 | 文章含 `$…$` / `$$…$$` 公式而环境缺 `matplotlib` | `local/venv/bin/pip install matplotlib` 后重新构建 |

部署、推送与清理仍按实际授权范围执行；本指南不构成操作授权。
