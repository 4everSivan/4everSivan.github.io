# 本地预览与发布指南

> **created**: 2026-11-06 ｜ **last-change**: 2026-11-06 ｜ **status**: active

文档 ID：GUIDE-DEPLOY。本指南描述当前静态站点的真实运行方式：站点由根目录 `index.html`、`assets/css/style.css` 与 `assets/js/main.js` 组成，**没有构建步骤**，因此没有依赖安装、打包产物或服务进程。

## 1. 前置条件与配置

- 平台：任意现代桌面浏览器（Chrome / Safari / Firefox 最近两个大版本）。
- 运行时：不需要 Node、Go 或包管理器；`python3` 仅用于可选的本地静态服务器。
- 字体：页面使用系统字体，中文回落到宋体（`Songti SC` / `SimSun`），拉丁字母与数字使用 `Times New Roman`。系统缺少对应字体时按 CSS 字体栈继续回落，功能不受影响。
- 配置与密钥：站点不需要环境变量、密钥或数据库；不存在需要注入的敏感配置。

## 2. 构建与启动

本项目没有构建产物，以下两种方式任选其一。

```sh
# 方式一：直接用浏览器打开（file:// 即可，无跨域资源）
open index.html

# 方式二：本地静态服务器，便于模拟真实路径与相对链接
python3 -m http.server 8000 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8000/
```

成功判断：

- 首页返回 HTTP 200，控制台无报错；
- 顶栏、引文、PROJECTS、SKILLS、页脚五个区块完整显示；
- 窄窗口（≤ 640px）下导航与列表正常换行，无横向滚动；
- 首次加载自动匹配浏览器浅色/深色偏好；点击顶栏主题按钮可切换并记住选择；两套主题文字对比度正常。

停止本地服务器使用 `Ctrl+C`，不需要清理构建缓存。

## 3. 发布与部署实况

站点是纯静态文件，由 `.github/workflows/pages.yaml` 在推送到 `main` 时部署：workflow 运行 `scripts/adflow-verify`，把 `index.html` 与 `assets/` 复制到 `public/` 并上传为 Pages artifact。发布流程：

1. 在授权范围内运行 `scripts/adflow-verify` 并取得 Exit 0；
2. 按项目提交规范提交；
3. 合并与推送需独立授权；
4. 在 GitHub 仓库 Settings → Pages 确认 Source 为「GitHub Actions」；
5. 推送后查看 Actions 中 `Deploy static site to GitHub Pages` 的运行结果；
6. 发布后访问 `https://4eversivan.github.io/` 核对线上表现。

## 4. 已知失败与处理

| 现象 | 排查 | 处理 |
|---|---|---|
| 页面无样式 | 检查 `assets/css/style.css` 路径与大小写 | 修正相对路径后刷新 |
| 中文不是宋体 | 当前系统缺少 `Songti SC` / `SimSun` | 安装字体或按设计文档扩充字体栈 |
| 刷新后主题回到系统偏好 | `localStorage` 被清理或在隐私模式下不可用 | 手动选择无法保存时的预期回退 |
| 主题按钮无反应 | JavaScript 被禁用或脚本未加载 | 属预期；主题按钮依赖脚本 |
| 线上仍是旧页面 | Pages workflow 失败或 Source 不是 GitHub Actions | 查看 Actions 日志与 Pages 设置，避免反复强刷掩盖问题 |
| 动效缺失 | 系统开启「减少动态效果」 | 属预期，设计对 `prefers-reduced-motion` 直接呈现终态 |

部署、推送与清理仍按实际授权范围执行；本指南不构成操作授权。
